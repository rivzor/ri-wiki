# Полноценная чистая установка Windows { data-search-exclude }

!!! warning "Важно перед началом"
    Перед любой установкой создайте резервные копии всех важных данных. Чистая установка полностью удалит содержимое выбранного раздела/диска.  

---

## Где скачать официальный ISO-образ Windows 11 { data-search-exclude }

Для установки Windows необходим образ системы. Загрузить его можно:

- Перейдите на https://www.microsoft.com/ru-ru/software-download/windows11
    1. Выберите «Скачать образ диска Windows 11 (ISO)» → Windows 11 (multi-edition ISO) → язык → 64-bit Download.

- Мой каталог оригинальных ISO-файлов: [* **нажми** *](download.md)

Образ должен быть формата `.iso` без модификаций, предпочтительно оригинальный, исключая сборки.

## Подготовка загрузочного носителя { data-search-exclude }
### Способ 1: Rufus (рекомендуется для одной Windows, с автоматическим обходом требований)  

Rufus - самый удобный инструмент для создания загрузочной флешки с возможностью автоматического обхода TPM 2.0, Secure Boot и требования к 4 ГБ RAM.

1. Скачайте последнюю версию Rufus с официального сайта: https://rufus.ie/ (портативная версия, установка не требуется). Подробное описание программы: [Rufus - создание загрузочных флешек.](download.md)
2. Вставьте флешку **минимум 8 ГБ** (все данные на ней будут удалены!).
3. Запустите Rufus → выберите флешку в поле **Устройство**.
4. Нажмите **ВЫБРАТЬ** → укажите скачанный ISO Windows 11.
5. Параметры (рекомендуемые для большинства ПК 2018+ года):
    - **Схема разделов:** GPT
    - **Целевая система:** UEFI (non CSM)
    - **Файловая система:** NTFS
    !!! tip "Когда выбрать MBR"
        Если компьютер очень старый (до 2012 года) и поддерживает только Legacy BIOS — выберите MBR и BIOS (или UEFI-CSM).
6. В выпадающем списке **Вариант образа** оставьте **Стандартная установка Windows** (если нужен обход — ниже).
7. Нажмите **СТАРТ**.
8. Откроется окно **Параметры пользовательского опыта Windows**:
    - Поставьте галочку **Удалить требование наличия 4 ГБ+ ОЗУ, Secure Boot и TPM 2.0** (если ПК не проходит проверку).
    - При необходимости также отключите сбор телеметрии, онлайн-учётную запись Microsoft и т.д.
9. Подтвердите форматирование → дождитесь завершения.

### Способ 2: Ventoy (мультизагрузочная флешка — несколько ISO на одном носителе)

Идеально, если нужна флешка для Windows + Linux-дистрибутивов + утилит.

1. Скачайте Ventoy с https://ventoy.net
2. Запустите **Ventoy2Disk.exe** → выберите флешку → **Install** (рекомендуется опция **Secure Boot Support**).
    
    ??? note "Скриншот"
        <figure markdown="span">
            ![Ventoy2Disk.exe](https://remontka.pro/images/ventoy-software-main.png){ width="400" }
        </figure>

3. После установки откроется раздел Ventoy (`exFAT`).
4. Скопируйте в него любые ISO (Windows 11, Linux Mint, MemTest и т.д.).
5. Для автоматического обхода требований Windows 11 создайте в корне флешки файл `ventoy/ventoy.json:`

``` json title="ventoy.json"
{
    "control": [
        { "VTOY_DEFAULT_MENU_MODE": "1" },
        { "VTOY_TREE_VIEW_MENU_STYLE": "0" },
        { "VTOY_WIN11_BYPASS_CHECK": "1" }
    ]
}
```

### Способ 3: Без флешки — установка через временный раздел на диске

Подходит, если нет флешки или второго ПК.

1. Скачайте ISO и смонтируйте его двойным кликом (или через Проводник → Правка → Подключить).
2. Откройте смонтированный диск → запустите setup.exe с зажатой клавишей ++shift++ + ++f10++ (откроется командная строка).
3. Создайте временный раздел (минимум 8 ГБ):

    ``` bash title="cmd"
    diskpart
    list disk
    select disk 0   (выберите диск, где есть свободное место, НЕ системный если возможно)
    create partition primary size=10000
    format fs=ntfs quick label=WIN11TEMP
    assign letter=W
    exit
    ``` 
    
4. Скопируйте содержимое ISO на новый раздел:

    ``` bash title="cmd"
    xcopy E:\*.* W:\ /E /H /C /I /Y   (E: — буква смонтированного ISO)
    ``` 

5. Перезагрузитесь в UEFI/BIOS (++del++, ++f2++, ++f10++ и т.д.) → Boot Menu (++f11++, ++f12++) → выберите загрузку с нового раздела UEFI: WIN11TEMP.
6. Установка пойдёт как с обычной флешки.

## Процесс чистой установки Windows 11

1. Загрузитесь с созданного носителя *(в BIOS отключите Secure Boot, если не обошли; приоритет загрузки — USB).*
2. Выберите язык → Установка.
3. Если появляется сообщение **«Этот компьютер не соответствует требованиям»** — обход уже применён *(Rufus/Ventoy)*, просто продолжайте.
4. Выберите **Выборочная установка** *(только для опытных пользователей)*.
5. Критически важный момент: удаление разделов и выбор схемы

    === "UEFI + GPT (рекомендуется для всех ПК 2015+)"
        Удалите ВСЕ разделы на целевом диске → останется «Нераспределённое пространство» → нажмите Далее.
        Установщик автоматически создаст GPT-разделы (EFI, MSR, основной, восстановление).
    === "Legacy BIOS + MBR (старые ПК)"
        Удалите разделы → создайте новый → форматируйте NTFS.

    ??? danger "Ошибка «Windows нельзя установить на диск... стиль разделов GPT/MBR»"
        - При загрузке в UEFI требуется GPT.
        - При Legacy BIOS — MBR.
        - Решение: в BIOS переключите режим (UEFI ↔ Legacy/CSM) или используйте ++shift++ + ++f10++ → `diskpart` → `clean` → `convert gpt` или `convert mbr`.

6. Установка файлов → перезагрузки.
7. **OOBE** (начальная настройка):
    - Отключите интернет (выдерните кабель/Wi-Fi), чтобы появилась возможность создать локальную учётную запись.
    - Или нажмите ++shift++ + ++f10++ → `oobe\bypassnro` → перезагрузка → появится опция «У меня нет интернета».
