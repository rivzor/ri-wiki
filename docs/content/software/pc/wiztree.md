# WizTree

![WizTree](https://static1.xdaimages.com/wordpress/wp-content/uploads/2024/07/wiztree-logo.png){ align=left width="70" loading=lazy }

WizTree — инструмент для анализа использования диска, работающий на NTFS. Сканирует за секунды и отображает результаты в виде treemap.

### Возможности  { data-search-exclude }

- Быстрое сканирование дисков
- Визуализация treemap для папок/файлов
- Поиск дубликатов файлов
- Экспорт результатов в CSV
- Portable-режим без установки
