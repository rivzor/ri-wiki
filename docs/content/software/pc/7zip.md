# 7-Zip
![7-Zip](https://www.7-zip.org/7ziplogo.png){ align=left width="70" loading=lazy }

7-Zip — легендарный архиватор с открытым исходным кодом, обеспечивающий максимальную степень сжатия благодаря формату 7z (LZMA/LZMA2).

### Возможности { data-search-exclude }
- Лучшая степень сжатия среди всех архиваторов
- Поддержка 7z, ZIP, RAR (только распаковка), TAR, GZIP, XZ и ещё 60+ форматов
- AES-256 шифрование архивов и имён файлов
- Полная интеграция в контекстное меню Проводника
- 100 % portable-версия без установки
- Проверка хэшей (SHA-256, CRC) и бенчмарк производительности
