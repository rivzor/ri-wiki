# ReVanced

![ReVanced](https://revanced.app/logo.svg){ align=left width="40" loading=lazy }

ReVanced — официальный наследник YouTube Vanced. Это не готовое приложение, а **платформа патчей** на базе ReVanced Manager. Позволяет модифицировать любые поддерживаемые приложения (YouTube, TikTok, Reddit, Twitch, Spotify и т.д.) без root.

### Возможности платформы  { data-search-exclude }
- Патчинг официальных APK без установки модифицированных сборок
- Полная блокировка рекламы в поддерживаемых приложениях
- Добавление Premium-функций (фон, скачивание, RYD, SponsorBlock и др.)
- Поддержка более 20 приложений (список постоянно растёт)
- Работа без root (через MicroG или без входа в аккаунт)
- Открытый исходный код и активное сообщество
